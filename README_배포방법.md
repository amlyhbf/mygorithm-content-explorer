# 맘고리즘 콘텐츠 탐색기 — 웹 배포판

이 파일은 `index.html` **와** `server.js` 를 함께 배포해야 작동합니다. HTML만 정적 호스팅에 올리면 자동 검색이 실패합니다.

## 빠른 배포 — GitHub + Render

1. GitHub에서 **새 저장소**를 만듭니다. (기존 `내맘대로 알고리즘` 프로젝트와 분리)
2. 이 폴더의 **index.html, server.js, package.json**을 저장소의 최상위에 업로드합니다. README와 `.gitignore`도 함께 업로드할 수 있습니다.
3. https://dashboard.render.com/ 에서 **New > Web Service**를 선택합니다.
4. GitHub 계정을 연결하고 방금 만든 저장소를 선택합니다.
5. 설정값:
   - Language / Runtime: `Node`
   - Branch: `main` (저장소의 실제 기본 브랜치로 맞춤)
   - Root Directory: 비움 (파일들이 저장소 최상위에 있을 때)
   - Build Command: `npm install`
   - Start Command: `npm start`
   - Instance Type: `Free` (선택 가능할 때)
6. 배포 완료 시 Render에서 제공하는 `https://<서비스이름>.onrender.com` 주소를 복사합니다.
7. PC에서 **기사·글 검색**, **영상 검색**, **후보 저장**, **CSV 다운로드**를 점검하고, 스마트폰에서도 같은 주소로 점검합니다.

## 매우 중요한 제한

- 웹사이트 주소는 공유되지만 **후보 보관함은 기기/브라우저별 localStorage**에 저장됩니다. 승민이의 휴대전화 데이터가 PC에 자동으로 동기화되지 않습니다.
- 결과를 다른 기기로 옮기려면 **CSV 내보내기 → CSV 불러오기**를 사용하세요. 중요한 자료는 CSV로 백업해야 합니다.
- 이 프로그램은 **한국어 위키백과 정보 글 + Wikimedia Commons 영상**을 기본 검색합니다. 뉴스 사이트 기사/유튜브 자동 수집은 아직 연결되지 않았습니다.
- 이 공유용 배포판에서는 브라우저에 API 키를 입력하는 기능을 비활성화했습니다. API 키가 필요한 기능은 서버에 비밀값으로 보관하는 방식으로 별도 개발해야 합니다.
- Render 무료 Web Service는 일정 시간 요청이 없으면 잠자기 상태가 되어 첫 접속이 느릴 수 있고, 이용량 제한이 있습니다.
- 링크를 아는 사람이 접근할 수 있습니다. 개인정보나 비공개 팀 문서, API 비밀번호는 업로드하지 마세요.
- 학교 활동용 실험 버전입니다. 사용성 테스트 결과를 반영하기 전까지 정식 서비스로 홍보하지 마세요.

## PC 로컬 실행(개발자용)

Node.js 20+ 설치 후 이 폴더에서 `npm start`를 실행하고 http://localhost:8765 를 엽니다.

## 점검 주소

Render 배포 후 `https://<서비스이름>.onrender.com/health`에 접속하면 `{"ok":true,...}` 형태의 상태를 볼 수 있습니다.

## 원본 프로그램 관계

`내맘대로 알고리즘` 본 사이트와 무관한 별도 실험 서비스입니다. 본 사이트에는 배포되지 않았습니다.
